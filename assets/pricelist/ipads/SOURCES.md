# iPad Pro M5 availability list: sources
Transparent PNGs supplied by City Store (originals in `src/`), trimmed and upscaled 3x (they were ~300 px).
- `ipadpro_m5_13_spaceblack.png` -> `public/pricelist/ipads/13.png`: both 13" cards.
- `ipadpro_m5_11_spaceblack.png` -> `public/pricelist/ipads/11.png`: the 11" card.
Sizes as given by City Store: 13" Wi-Fi + 5G 256 GB / 512 GB / 1 TB / 2 TB; 13" Wi-Fi 256 GB / 512 GB; 11" Wi-Fi 256 GB / 2 TB.
- `ipad_a16_four_colours.png` (301 px, Blue / Silver / Pink / Yellow) -> `public/pricelist/ipads/a16.png` (trimmed, upscaled 3x). iPad A16 Wi-Fi 128 GB.
- Galaxy Tab A7 Lite (Silver, 32 GB): `galaxy_tab_a7lite_boxes_shop_photo.webp` (City Store shop photo) -> `tab_a7lite.png`: only the lower box is cut out (polygon mask), so the shop wall, the figure and the top box are left out. It is a photo of the sealed box, not an official render.
